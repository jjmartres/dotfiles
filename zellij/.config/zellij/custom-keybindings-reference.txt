SESSION MANAGEMENT:
  Ctrl+Alt+D  →  Detach from session
  Ctrl+Alt+Q  →  Quit/Close session  
  Ctrl+Alt+W  →  Open session manager

PANE FOCUS MOVEMENT:
  Ctrl+Alt+H  →  Move focus LEFT
  Ctrl+Alt+J  →  Move focus DOWN
  Ctrl+Alt+K  →  Move focus UP
  Ctrl+Alt+L  →  Move focus RIGHT

PANE ACTIONS:
  Ctrl+Alt+F  →  Toggle fullscreen

TAB NAVIGATION:
  Ctrl+Alt+]  →  Previous tab
  Ctrl+Alt+[  →  Next tab

NOTE: These use Ctrl+Alt (NOT Cmd). Terminal apps can't access Cmd key.

╠═══════════════════════════════════════════════════════════════════════╣
║  KEY NOTES                                                            ║
╠═══════════════════════════════════════════════════════════════════════╣

  • Your custom keybindings use Ctrl+Alt (TWO modifiers)
  • Terminal apps cannot access the Cmd/Super key
  • These work from any mode (except locked)
  • Default zellij keybindings remain unchanged
  • Press Esc or Enter to exit any mode
  • All configs are compatible with LazyVim

╠═══════════════════════════════════════════════════════════════════════╣
║  AVOIDING LAZYVIM CONFLICTS                                           ║
╠═══════════════════════════════════════════════════════════════════════╣

  Your Ctrl+Alt+H/J/K/L bindings won't conflict with LazyVim because:
  • LazyVim uses Ctrl+W for window management (not Ctrl+Alt)
  • LazyVim uses plain Ctrl for other functions
  • Ctrl+Alt combinations are generally free

  If you experience conflicts, use Ctrl+G to lock zellij.
